How it works

Three commands, one file. No backend required for the CLI; a hosted control plane is optional.

01

Init

Scaffold a starter policy from a template.

policyctl init --template full
02

Wire

Generate provider hook glue for Claude, Codex, or Cursor.

policyctl gen claude policyctl gen codex policyctl gen cursor
03

Check

Gate the diff in CI. Get a full violation feed in the dashboard.

policyctl check policyctl check --report

See it in action

policyctl check
$ policyctl check FAIL migrations-via-generator DB migrations must be produced by `make migrate`, never handwritten. FAIL no-secrets-in-commits Reject commits that add obvious secret patterns. 2 blocking · 0 warnings — build stopped

What you can enforce

A rule is a matcher set, an enforce level, and a scope. Compose them. Allowlist reviewed exceptions. Tag them.

DB
block · both

Migrations via generator

Block any migration file that lacks the generator signature — at hook time and in CI.

🔒
block · hook

No protected edits

Prevent agents from touching README, package.json, tsconfig.json, or any path you choose.

⚠
fail · ci

No secrets in commits

Regex-detect AWS keys, GitHub tokens, OpenAI keys in the diff and fail the build.

✓
warn · ci

Tests for source

Warn when a src/ change ships without a matching test file.

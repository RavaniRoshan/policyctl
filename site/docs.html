policyctl docs

Provider-agnostic policy runtime for coding agents.

Install

npm install -g @policyctl/cli # or, no install: npx @policyctl/cli check

Quickstart

policyctl init --template full policyctl list policyctl gen claude # or codex / cursor policyctl check # gate the diff in CI

CI

# .github/workflows/policy.yml name: policyctl on: [push, pull_request] jobs: check: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: actions/setup-node@v4 with: { node-version: '20' } - run: npx @policyctl/cli check

Hosted control plane (optional)

The CLI is free and local-first. The hosted control plane is what teams pay for: one policy, enforced across every agent and repo, with an audit trail.

policyctl login --email you@company.com policyctl push # publish your policy policyctl check --report # send violations to the feed

Rules reference

Match a rule against a tool call (hook) or a git diff (ci):

  • path — glob over the file the tool touches (hook) or changed files (ci)
  • command — regex over a shell command (e.g. the Bash tool); hook only
  • tool — tool name (exact, or /regex/); hook only
  • diff_contains — substring that must be present in the diff; ci only
  • diff_not_contains — substring that must be absent (e.g. a generator signature); ci only
  • diff_regex — regex over the full diff text; ci only
  • diff_paths_glob — glob that must match at least one changed file; ci only
  • diff_paths_not_glob — glob that must match no changed file; ci only

Commands

◆

init

Scaffold a .policyctl.yml from a template.

≡

list

Show loaded rules and their scope.

✓

check

Run the CI/diff gate. Non-zero on violation.

⚡

eval

Run the hook evaluator (reads JSON on stdin).

⚙

gen

Generate Claude / Codex / Cursor hook glue.

+

doctor

Verify hooks are wired correctly.

?

trace

Explain which matchers fire for a given input.

▦

test

Run the policy against a fixture suite.

☁

login / push / pull

Optional hosted control plane (org policy sync).

↑

report

Send a violation result to the hosted feed.

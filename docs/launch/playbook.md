## Red lines (do not cross)

1. Never ask anyone to create a fresh PH account just to upvote — discounted and flags the launch
2. Never buy votes or use vote exchanges (launchpact etc.) — bannable
3. HN: never ask for upvotes; just answer questions in the thread
4. Reddit: 3 posts, 3 subs, 3 angles; never delete-and-repost for traction
5. Every DM personalized; no bulk paste

## Contingencies

- **HN thread takes off**: everything else pauses; live in that thread for 3–4h. HN front page is the single biggest traffic event available today.
- **A Reddit post gets removed**: do NOT repost in the same sub; move to the next scheduled one.
- **PH comments turn critical**: engage technically, never defensively. Comment depth helps ranking even when the comment is skeptical.
- **Site traffic spike**: watch Worker for errors; if D1/KV issues appear, ping agent — repo access is ready.

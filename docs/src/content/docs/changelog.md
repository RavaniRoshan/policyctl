`policyctl` follows semantic versioning. The canonical release history lives on GitHub:

- **[Releases](https://github.com/RavaniRoshan/policyctl/releases)** — versioned notes for every CLI, engine, and Cloud change
- **[Commits](https://github.com/RavaniRoshan/policyctl/commits/main)** — full main-branch history

The npm feed (`@policyctl/cli`) and the Cloud API are deployed from `main`; the dashboard's `/dashboard/policies` feed records every pushed policy version for your organization.

title: Agent Hook Formats

---

`policyctl` bridges heterogeneous coding agent architectures using standard hook configuration files.

---

## 1. Claude Code Hook Format

Claude Code looks for `.claude/settings.json` in the project root or user home directory.

### Configuration (`.claude/settings.json`)

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "policyctl eval --hook"
          }
        ]
      }
    ]
  }
}
```

### Stdin Payload Received from Claude
```json
{
  "tool_name": "Edit",
  "tool_input": {
    "file_path": "src/index.ts",
    "old_string": "const x = 1;",
    "new_string": "const x = 2;"
  }
}
```

## 2. Cursor Hook Format

Cursor reads `.cursor/hooks.json` to execute lifecycle shell scripts.

### Configuration (`.cursor/hooks.json`)

```json
{
  "version": 1,
  "hooks": {
    "beforeShellExecution": [
      {
        "command": "policyctl eval --hook",
        "matcher": ".*"
      }
    ],
    "afterFileEdit": [
      {
        "command": "policyctl eval --hook",
        "matcher": ".*"
      }
    ]
  }
}
```

## 3. OpenAI Codex Hook Format

Codex evaluates `.codex/hooks/hooks.json`.

### Configuration (`.codex/hooks/hooks.json`)

```json
{
  "version": 1,
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "shell|apply_patch|Write|Edit|MultiEdit",
        "hooks": [
          {
            "type": "command",
            "command": "policyctl eval --hook"
          }
        ]
      }
    ]
  }
}
```

---

## 4. Git Pre-Commit Fallback

To catch commits made outside an AI assistant (or by agents that do not yet support execution hooks), `policyctl gen` installs a standard git hook at `.git/hooks/pre-commit`:

```sh
#!/bin/sh
# Generated by policyctl
policyctl check || exit 1
```

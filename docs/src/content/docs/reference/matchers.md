---
title: Matchers Reference
description: Complete technical reference for all 8 deterministic matchers in policyctl.
---

The core engine in `packages/core` evaluates 8 deterministic matchers. Matchers are partitioned into **Hook-scope** and **CI-scope** sets.

---

## Matcher Overview

| Matcher | Applicable Scope | Argument Type | Description |
|---|---|---|---|
| `path` | `hook`, `ci` | `string` (glob) | Evaluates against targeted file path. |
| `command` | `hook` | `string` (regex) | Evaluates against shell command execution. |
| `tool` | `hook` | `string` (name / regex) | Evaluates against the agent tool name. |
| `diff_contains` | `ci` | `string` (literal) | Asserts that diff patch contains exact substring. |
| `diff_not_contains` | `ci` | `string` (literal) | Asserts that diff patch **omits** exact substring. |
| `diff_regex` | `ci` | `string` (regex) | Evaluates regular expression against unified diff. |
| `diff_paths_glob` | `ci` | `string` (glob) | Asserts that at least one changed file matches glob. |
| `diff_paths_not_glob`| `ci` | `string` (glob) | Asserts that **no** changed file matches glob. |

---

## 1. `path`
- **Scope**: `hook` and `ci`
- **Engine**: Evaluated using `picomatch`.
- **Behavior**:
  - **Hook Mode**: Checks `event.tool_input.file_path`. If no file path is provided in the tool call, returns `false`.
  - **CI Mode**: Checks against all modified file paths in the commit diff. Returns `true` if any file matches.
- **Example**:
  ```yaml
  when:
    path: "db/migrations/**/*.sql"
  ```

---

## 2. `command`
- **Scope**: `hook`
- **Engine**: Regular Expression (`RegExp`). Supports case-insensitivity with `(?i)`.
- **Behavior**: Matches against `event.tool_input.command` (used by tools like `Bash`, `ExecuteCommand`).
- **Example**:
  ```yaml
  when:
    command: "(?i)rm\\s+-rf\\s+/"
  ```

---

## 3. `tool`
- **Scope**: `hook`
- **Behavior**:
  - **Exact Match**: `tool: "Bash"` matches only the `"Bash"` tool.
  - **Regex Match**: If enclosed in slashes (`/Edit|Write/`), evaluates as a regular expression against the tool name.
- **Example**:
  ```yaml
  when:
    tool: "/(Write|Edit|MultiEdit)/"
  ```

---

## 4. `diff_contains` / `diff_not_contains`
- **Scope**: `ci`
- **Engine**: Substring check (`String.prototype.includes`).
- **Behavior**:
  - `diff_contains: "X"` evaluates to `true` if `X` appears in the unified diff patch.
  - `diff_not_contains: "X"` evaluates to `true` if `X` is **absent** from the unified diff patch. Commonly used to enforce generator signatures.
- **Example**:
  ```yaml
  when:
    all:
      - path: "db/migrations/**"
    any:
      - diff_not_contains: "! Generated by make migrate"
  ```

---

## 5. `diff_regex`
- **Scope**: `ci`
- **Engine**: Regular Expression (`RegExp`).
- **Behavior**: Executes regex against the entire unified diff text. Supports multiline matches and `(?i)` flag.
- **Example**:
  ```yaml
  when:
    diff_regex: "(?i)(aws_secret_access_key|ghp_|sk-[a-z0-9]{20,})"
  ```

---

## 6. `diff_paths_glob` / `diff_paths_not_glob`
- **Scope**: `ci`
- **Engine**: Glob matching via `picomatch`.
- **Behavior**:
  - `diff_paths_glob`: True if `files.some(f => glob(f.path))`.
  - `diff_paths_not_glob`: True if `!files.some(f => glob(f.path))`.
- **Example (Companion Tests)**:
  ```yaml
  when:
    all:
      - diff_paths_glob: "src/**/*.ts"
    any:
      - diff_paths_not_glob: "**/*.test.ts"
  ```

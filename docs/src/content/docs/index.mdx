**Supported:** Claude Code · Cursor · Codex · GitHub Actions

## Install

```bash
npx -y @policyctl/cli@latest init --all
```

## How policyctl works

```
Agent
  ↓
Hook (PreToolUse)
  ↓
policyctl eval (<12ms, local)
  ↓
ALLOW / BLOCK
  ↓
Agent continues or receives remediation
```

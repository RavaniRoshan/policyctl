## Quick Installation

The `policyctl` CLI is a single static, local-first binary with zero telemetry and zero external network dependencies:

```bash
# Initialize policyctl across all detected coding agents
npx -y @policyctl/cli@latest init --all

# Run a local diagnostic check
npx -y @policyctl/cli@latest doctor
```

## How It Works

```
+-------------------+       +-------------------+       +-------------------+
|    Claude Code    |       |   OpenAI Codex    |       |   Cursor Editor   |
+---------+---------+       +---------+---------+       +---------+---------+
          |                           |                           |
          +---------------------------+---------------------------+
                                      |
                      PreToolUse Hook / Shell / Edit
                                      v
                        +----------------------------+
                        |  policyctl eval --hook     |
                        |  Evaluates .policyctl.yml  |
                        +--------------+-------------+
                                       |
                +----------------------+----------------------+
                |                                             |
         exit 0 (Allow)                                exit 2 (Deny)
                v                                             v
        Tool Call Proceeds                            Operation BLOCKED
```
